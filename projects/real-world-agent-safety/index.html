Research agenda

Evaluation for Real-World AI Systems and Agents

I examine how to build evaluations for real-world AI systems and agents. I synthesize research evidence and professional guidance into evaluation criteria, operationalize these criteria through benchmarks, and build infrastructure for constructing benchmarks and running evaluations under controlled conditions. Domain experts and shared-task communities contribute real workflows, difficult cases, and output review, creating a feedback loop between evaluation design and practice.

01 ·Evidence

Define what evaluation should measure

This work combines empirical reviews, professional guidance, stakeholder priorities, and reporting frameworks to define the relevant outcomes, risks, tested settings, and work products before tasks or metrics are chosen. This grounding matters because benchmarks otherwise risk rewarding narrow proxies that do not reflect their intended use.

03 ·Infrastructure

Build benchmarks and run controlled evaluations

This step builds the controlled environments needed to construct benchmarks and run them consistently. It includes versioned files, search results, tool access, workspace updates, trajectories, and final artifacts so benchmark builders can reproduce what an agent saw and separate system behavior from environment inconsistencies.
